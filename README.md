# 账本有数 · 个人 / 家庭收支分析器

> 云南大学 TRAE「AI × 经济学」赛题五参赛作品
> 离线单页应用：双击 `web/index.html` 即可演示，不联网、不安装环境、数据不出本机。

## 一、怎么运行

**看成品（推荐评审现场用这个）**

1. 双击 `web/index.html`，用 Chrome / Edge 打开。
2. 右上角切换 `D1 个人 / D2 家庭 / D3 多账户`，左上角切换统计月份。
3. 顶部「录入」页签可现场输入一句话记账，例如 `昨天午饭 25 元`。
4. 右上角「3 分钟演示」可一键走完 8 步讲解剧本。

**需要单文件交付时**

```bash
python tools/build_single_file.py   # 生成 账本有数_单文件.html
```

单文件把样式、ECharts、数据和逻辑全部内联，双击即可运行，适合拷给评委。

> `file://` 下也能正常运行：数据以 `data.js` 注入，图表库 `echarts.min.js` 为本地文件，全程无 `fetch`、无 CDN。

**重跑数据管线（验证可复现）**

```bash
python pipeline/build_clean.py      # 清洗、去重、对账、异常标记
python pipeline/classify.py         # 规则引擎 + 字级朴素贝叶斯，输出评测
python pipeline/nl_parse.py         # 批量自然语言解析与 143 条自测
python pipeline/build_insight.py    # 自动小结、预算预警、统计局八大类对照
python tools/build_web_data.py      # 合并为 web/data.js
```

环境：Python 3.10+，**只用标准库**（`csv / json / statistics / math / re / datetime / collections`），无 pandas、无 sklearn、无第三方依赖。

## 四、做法要点（答辩用）

1. **双引擎分类**：先用赛题给的 15 条关键词规则（顺序优先级固定）覆盖全部 692 笔，规则 100%；再用字级 unigram+bigram 多项式朴素贝叶斯做对照，**5 折分层交叉验证**（每折 138 笔、训练 554 笔），各折 95.17% / 97.16% / 93.48% / 97.78% / 96.24%，均值 **95.97% ± 1.52%**，并导出混淆矩阵与每类 P/R/F1。两行数字都远超 85% 验收线，且**特征只用描述**，规避标签泄漏。
2. **金额零误差**：清洗阶段按 `交易ID` 去重（D1 265→262，D2 289→287），保留逐月「原始合计 / 清洗合计 / 差额」，三组差额全部 0.00，页面「趋势 → 月度对账」可见。
3. **自然语言记账**：前端实现相对日期（今天/昨天/前天/上周五）、日期继承（同一行后续笔沿用月份）、金额单位（元/块/rmb）、收支类型推断与本地规则分类；离线管线另对 D3 的 143 条原始记录做了逐条自测。
4. **异常识别**：`金额 ≥ max(500, 同类中位数 × 2.5)` 或原始备注含「疑似大额异常」，三组分别命中 2 / 8 / 2 笔，避免 IQR 规则误报过多。
5. **官方口径对照**：把工具分类按赛题映射表归入统计局八大类，与 2026 年前三季度全国/城镇/农村结构做占比对照，明确标注「样本为模拟数据，仅作结构对照」。

## 五、进阶能力（两轮累计）

1. **双引擎复核闭环**：前端用 `model.json` 里的参数完整复现朴素贝叶斯推理（字级 unigram+bigram、拉普拉斯平滑，与 `pipeline/classify.py` 完全一致），逐笔与规则引擎比对；不一致的交易进入「复核」队列，可「采用规则 / 采用模型 / 改其他分类」，确认后所有页签实时重算，并生成复核记录。
2. **预算沙盘**：预算页每个分类的月预算可直接编辑，改完立刻重算预算执行率、超支分类与异常提示；支持一键「恢复默认预算」。改动会写回本地存储。
3. **账户维度**：结构页新增多账户支出分布，点击柱条自动跳到明细并筛选该账户（D1 两个账户、D2/D3 各四个账户）。
4. **本地持久化**：新增记录、复核结论、预算调整写入 `localStorage`，刷新不丢；「清空本地改动」可一键回到初始账单。
5. **报告升级**：报告新增「人工复核与预算调整」章节，把双引擎分歧数、人工确认结果、自定义预算数一并打印。
6. **固定 / 弹性支出拆分**：结构页把支出拆成「居住 / 通讯 / 交通」的固定部分与其余弹性部分，给出金额、占比与固定支出覆盖率，直接回答「哪些钱可以省」。
7. **结余率走势**：趋势页新增双 Y 轴图，柱为每月结余金额（正绿负红），折线为「（收入 − 支出）÷ 收入」的结余率。
8. **环比变化瀑布**：用“透明占位 + 变化量”堆叠画瀑布图，上月合计 → 各分类增减 → 本月合计，涨红跌绿，一眼看出差额来自哪里。
9. **异常卡片补上下文**：每张异常卡同时给出「同类中位数」「同类中位数倍数」「剔除本笔后本月支出」，避免只看到一个孤立的大数字。
10. **规则强度替代置信度**：明细与单笔录入用「强 / 中 / 弱」表示规则命中强度（命中 ≥2 个关键词为强、1 个为中、兜底为弱），可解释且不冒充概率。
11. **5 折交叉验证**：`classify.py` 改为分层 5 折，输出逐折准确率、均值与标准差；复核页新增评测卡，展示规则准确率、模型均值 ± 波动、折间极差与每折样本量。
12. **3 分钟演示剧本**：右上角按钮启动 8 步讲解（概览 → 结构 → 趋势 → 预算 → 异常 → 复核 → 录入 → 报告），自动切页并高亮目标区域，支持上一步 / 下一步 / Esc 退出。
13. **单文件交付**：`tools/build_single_file.py` 把 CSS、ECharts、data.js、app.js 全部内联，生成约 1.4 MB 的 `账本有数_单文件.html`，双击即用。

## 六、已知局限（主动交代，避免过度断言）

- D3 批量文本表头写 23 笔，实际可解析 12 笔，以实际内容为准，已在 `nl_parse.json` 的 `note` 中记录。
- 143 条自测中，2 条「昨天/前天」因原始 CSV 生成锚点为 2025-11-16、而解析基准日为 2025-12-01，日期相差两周；3 条「网购」被规则判为购物、真值为学习。均如实保留在 `errors` 里，未做人为修饰。
- 自动小结只做描述性统计，不做因果推断；八大类对照不代表居民总体。

## 七、5 分钟口播稿

**问题**（30 秒）
个人和家庭账本最大的痛点不是「记不下来」，而是「记了看不懂」：分类靠手填、汇总对不上、预算形同虚设。

**做法**（90 秒）
我们做了三层：第一层清洗与对账，按交易 ID 去重，逐月逐类核对到 0.00；第二层双引擎分类，规则引擎 100%、字级朴素贝叶斯 5 折交叉验证 95.97% ± 1.52%，两行都超过 85% 的验收线，且只喂「描述」，不碰分类标签；第三层把它变成能用的界面——10 个页签，从概览、结构、趋势、预算、异常到明细下钻，结构页直接拆出固定支出与弹性支出，趋势页用结余率和瀑布图解释钱的变化，两套引擎结论不一致的交易会进入「复核」队列由人拍板，改完预算沙盘全站实时重算，还能用一句「昨天午饭 25 元」直接记账，并和一键打印的报告打通。

**三个可验证证据**（90 秒）
1. 三组清洗后笔数 262 / 287 / 143，逐月对账差额全部 0.00，页面上能直接看到「差额 0.00 ✓」。
2. 分类评测两行：规则 100.00%、模型 5 折均值 95.97% ± 1.52%，附逐折准确率、每类 P/R/F1 与混淆矩阵。
3. 断网双击 `index.html` 即可运行，顶部常驻「网络请求 0」；图表点一下就能落到对应明细。

**局限与下一步**（30 秒）
样本是脱敏模拟数据，结论只做描述性统计；下一步会把分类器换成可在线增量学习的版本，并加入多账户自动归集。

> 全程无网络请求，数据不离开本机。
